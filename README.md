# Qian清理 (QianClean)

> 一个 Windows 内存 / CPU / GPU 释放 + 360 级垃圾清理的命令行工具，单文件、绿色免安装、一键运行。

**作者**: 白小谦　|　**反馈邮箱**: [qianxlfk@163.com](mailto:qianxlfk@163.com)　|　**开源协议**: AGPL-3.0-or-later

---

## ✨ 功能一览

| 菜单 | 功能 | 释放量显示 |
|---|---|---|
| `1` 一键全面清理 | 内存释放 + **19 类垃圾**扫描清理 + 总报告（360 级三阶段流程） | 内存 / 磁盘 / CPU / 显存全量化 |
| `2` 内存急救 | 结束卡死进程 + 修剪全部工作集 + 清空待机列表（纯内存，快） | 净释放 MB + 工作集移出 MB |
| `3` 垃圾扫描预览 | 只扫描不删除，列出每类垃圾的大小 / 文件数，看完再决定 | 合计发现垃圾 X GB |
| `4` 深度可选工具 | 事件日志 / DISM 组件清理 / Prefetch / 开发者缓存 / 重启资源管理器 / 关闭 WSL / 重置 SysMain / 回收站 | 每项独立显示释放量 |
| `5` 卡死进程管理 | 列出全部"无响应"窗口进程，按 PID 或全部结束 | 每个进程的内存释放量 |
| `6` 资源占用 TOP | 内存 Top10 / CPU Top8 排行，可结束指定 PID | 结束进程释放量 |
| `7` GPU 状态 | 显卡信息、NVIDIA 实时状态、结束占显存的进程 | 显存释放 MiB |

**支持一次多选**：输入 `23` = 先内存急救再垃圾扫描；`1 3 4`、`134`、`1，3、4` 均可识别，依次执行。

## 🚀 使用方法

1. **双击 `start.bat`（入口文件）或 `Qian清理.bat`**
2. UAC 弹窗点"是"（需要管理员权限才能完整清理；拒绝则以受限模式继续）
3. 直接按**回车** = 一键全面清理，或输入菜单编号

系统要求：Windows 10 / 11（内置 PowerShell 5.1，无需安装任何依赖）。

## 📋 扫描覆盖的 19 类无用数据

临时文件（用户/系统）、Windows 更新缓存、传递优化缓存(DO)、系统日志（CBS / DISM / MoSetup / 服务日志）、崩溃转储（内核 / 程序）、错误报告（系统 / 用户）、显卡缓存（DirectX / NVIDIA / AMD）、缩略图与图标缓存、系统网页缓存、浏览器缓存（Edge / Chrome）。

内存释放手段：结束无响应进程（带保护名单）、逐进程 EmptyWorkingSet、系统级全量工作集清空、待机列表(Standby)清空、DNS 缓存 / 剪贴板清空。

## 🛡️ 安全设计

- **40+ 系统关键进程保护名单**（lsass / svchost / dwm / explorer 等）绝不结束
- 临时文件只清理 **2 小时前**的，正在使用的文件自动跳过（锁定即跳过）
- 破坏性操作（回收站 / 事件日志 / WSL / 重启资源管理器）**全部独立二次确认**
- 不触碰任何用户数据（微信/QQ 聊天记录、浏览器书签密码等）
- 所有清理均可安全再生：缓存会在使用中自动重建
